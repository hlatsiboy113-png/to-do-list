# 📝 To-Do List App

A simple, responsive To-Do List web application built using **HTML, CSS, and Vanilla JavaScript**.  
This project demonstrates DOM manipulation, event handling, and local storage in the browser.

---

## 🚀 Features

- ➕ Add new tasks
- ✔️ Mark tasks as complete/incomplete
- ❌ Delete tasks
- 🔍 Filter tasks (All / Active / Completed)
- 💾 Saves data using `localStorage` (persists after refresh)
- ⌨️ Add tasks using Enter key

---

##  Built Using

- HTML5 – Structure
- CSS3 – Styling
- JavaScript (Vanilla) – Logic & functionality
- Local Storage – Data persistence
